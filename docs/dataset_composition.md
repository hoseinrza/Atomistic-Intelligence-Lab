# Composition of the paper's DFT database (Supplementary Tables 1–3)

Faithful transcription of the structure-group composition of the database of
Purja Pun, Batra, Ramprasad & Mishin, *Nat. Commun.* **10**, 2339 (2019),
from the paper's Supplementary Information (SI PDF, obtained from the
journal page on 2026-11-21; stored git-ignored under `data/raw/si_2019/`).

The paper is open access (CC BY 4.0); this transcription is for scientific
documentation with attribution.

**What the SI contains:** composition only (group names, atom counts,
configuration counts, physical conditions). **No atomic positions and no
energies** are included — the raw database itself is available only from the
corresponding author (Y. Mishin), see `data/README.md`.

**Provenance (stated in the SI):** the data marked `*` were computed in the
2019 paper; **all remaining data were randomly selected from the database
generated by Botu & Ramprasad** [V. Botu & R. Ramprasad, *Phys. Rev. B*
**92**, 094306 (2015); *Int. J. Quantum Chem.* **115**, 1074 (2015)] — the
same refs. 20–21 the paper credits for its DFT methodology. That underlying
database is **not publicly distributed** (verified 2026-11-21; only the
fitted "AGNI" Al potential files are public via the LAMMPS potential
repository), so obtaining it requires an author request as well.

## Independent arithmetic verification (project policy)

Sums recomputed from the transcribed rows (never trusting the printed
totals):

* **Testing table:** row sum = **26 425** — matches the printed total
  exactly.
* **Training tables:** row sum of N_tv = **3643**, printed total **3649**
  (Δ = 6). Row sum of N_A·N_tv = **127 544** atoms, main-text value
  **127 592** (Δ = 48). Both deltas are simultaneously consistent with one
  missing group of N_A = 8, N_tv = 6 — either a group absent from the
  printed tables or an inconsistency in the SI itself. **Flagged; not
  resolved by the SI.** Consequence: group-level composition is reliable
  for qualitative planning (relative dataset weights), but exact per-group
  reconstruction of the training database from the SI alone is not
  possible.
* 46 distinct (Structure, Group, condition) rows appear in the training
  tables; group numbers run 1–44 with gaps (17, 29–34, 39 unused).

## How this maps to the alternative-database design

The composition defines the target mix for any alternative database built
under the methodological-reproduction workflow (`data/README.md`):
crystals under isotropic/uniaxial strain (7 structures), hot FCC MD at
several lattice parameters, surfaces with adatoms, vacancy cells, clusters
up to 79 atoms, grain boundaries, and a stacking-fault relaxation. The
selected alternative dataset (ANI-Al, `data/README.md`) covers the crystal,
MD-snapshot, melt, and cluster character of this mix but lacks slabs,
grain boundaries, and stacking faults — recorded there as a deviation.
